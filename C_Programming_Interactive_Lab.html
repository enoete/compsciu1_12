🚀 Welcome to C Programming!

🎮 Why C? The Origin Story

C was created at Bell Labs in 1972 to write the UNIX operating system. It became so powerful that today Python, Java, JavaScript, and even Minecraft's server tools all trace their roots back to C. Learning C means learning the grandfather of modern programming.

⚠️ Syntax Rule #1: Every statement ends with a semicolon ;

Forgetting a semicolon is the #1 beginner error in C. Every single statement must end with ; — it tells the compiler "this instruction is complete." The only exceptions are #include directives and lines with { }.

scanf — Accepting Input

Syntax — Note the & (ampersand)!

scanf("%format_specifier", &variableName);

The & means "the memory address of" — it tells scanf exactly WHERE in memory to store the value the user types. Forgetting the & is the #2 most common beginner error!

#include <stdio.h>
int main() {
    int age;
    float height;
    char initial;

    printf("Enter your age: ");
    scanf("%d", &age);           // &age = store here

    printf("Enter your height (m): ");
    scanf("%f", &height);

    printf("Enter your first initial: ");
    scanf("%c", &initial);        // for char, no space before %c

    printf("Hello %c! You are %d years old and %.2f m tall.\n",
            initial, age, height);
    return 0;
}

🎮 What does %.2f mean?

The .2 tells printf to show exactly 2 decimal places. So 1.75000 becomes 1.75. You can use %.1f, %.3f, etc. Super useful for displaying money, scores, and measurements!

🔑 Syntax vs Semantics

Two types of errors you will encounter in C. Understanding the difference will save you hours of debugging!

📐 Syntax Error

Breaking the grammatical RULES of C. The compiler catches these before your program runs — it won't even compile.

// Missing semicolon
int age = 18         // ❌ error!

// Wrong brackets
printf("Hello"       // ❌ missing )

// Undeclared variable
score = 90;          // ❌ never declared

🧠 Semantic Error

The code is grammatically correct (compiles!) but the MEANING or LOGIC is wrong. These are trickier — you find them by testing.

// Wrong formula — divides 2 numbers
// instead of averaging 3
avg = (a + b) / 2;  // should be / 3

// Assignment instead of comparison
if (x = 5)          // should be ==

🎮 The Minecraft Analogy

Syntax error = trying to place a block in mid-air with no support — the game (compiler) won't let you do it at all.
Semantic error = building a house with the door on the ceiling — it compiles (builds) fine but the logic makes no sense when you try to use it!

Pre vs Post Increment Challenge

Given int x = 6, y = 7; — predict the output of these printf statements. (Hint: 6-7 might mean something! 👀)

x=6, y=7

Line 3: printf(++y) → y becomes 8 FIRST, then prints 8
Line 4: printf(y)   → prints 8  (y is still 8)

🔀 Conditional Branching (if / else)

Programs often need to make decisions. The if statement lets your program take different paths based on conditions.

Syntax

if (condition) {
    // code runs if condition is TRUE
} else {
    // code runs if condition is FALSE
}

Nested if / else-if

When you have more than two options, chain them with else if:

if (condition1) {
    // code part 1
} else if (condition2) {
    // code part 2
} else if (conditionN) {
    // code part N
} else {
    // none of the above
}

🔄 Switch / Case Statement

🤔 WHY SWITCH?

When you have many else if branches checking the SAME variable, code becomes hard to read. switch is cleaner and the compiler optimises it to run faster!

Step 1: The Problem Without Switch

Imagine a Minecraft shop menu with 4 items. Using if/else:

// WITHOUT switch — gets messy fast!
if (choice == 1) {
    printf("You bought: Sword\n");
} else if (choice == 2) {
    printf("You bought: Shield\n");
} else if (choice == 3) {
    printf("You bought: Potion\n");
} else if (choice == 4) {
    printf("You bought: Armor\n");
} else {
    printf("Invalid choice!\n");
}

Step 2: Refactored WITH Switch

// WITH switch — clean, fast, professional!
switch (choice) {
    case 1:
        printf("You bought: Sword\n");
        break;
    case 2:
        printf("You bought: Shield\n");
        break;
    case 3:
        printf("You bought: Potion\n");
        break;
    case 4:
        printf("You bought: Armor\n");
        break;
    default:
        printf("Invalid choice!\n");
}

⚠️ NEVER forget break!

Without break, execution "falls through" to the next case automatically! This is a common beginner bug. Always end each case with break; unless you intentionally want fall-through.

Switch Rules

  • The variable in switch() must be an integer or character
  • Each case is checked for equality — no ranges allowed
  • default runs if no case matches (like the final else)
  • break exits the switch after a match
  • Case statements execute faster than long if-else chains

Textbook Example: Favourite Dessert

#include <stdio.h>
int main() {
    char Choice;
    printf("What is your favourite dessert? :\n");
    printf("a) Cheese cake\n");
    printf("b) Ice Cream\n");
    printf("c) Bread Pudding\n");
    scanf("%c", &Choice);
    switch(Choice) {
        case 'a':
            printf("Take a slice of the cheese cake\n");
            break;
        case 'b':
            printf("Have a serving of Ice Cream\n");
            break;
        case 'c':
            printf("Lots of pudding for you!\n");
            break;
        default:
            printf("No desert for you today!\n");
    }
    return 0;
}

🔁 The For Loop

Use a for loop when you know exactly how many times you want to repeat — you have a finite, countable number of iterations.

Syntax: Three parts in ONE line

for (initialisation; condition; increment/decrement) {
    // loop body — runs while condition is true
}

1. Initialisation: Set up the counter (i = 0) — runs ONCE at start
2. Condition: Keep looping while this is true (i < 10)
3. Increment: Change counter each iteration (i++)

🔁 For Loop Flow

  1. Initialise counter
  2. Check condition → FALSE? Exit
  3. Execute loop body
  4. Increment counter
  5. Go back to step 2

When to use For:

  • Printing multiplication tables
  • Counting from A to B
  • Processing fixed-size lists
  • Repeating exactly N times

Textbook Example: Multiplication Table

#include <stdio.h>
int main() {
    int a;
    printf("Enter a number: ");
    scanf("%d", &a);
    printf("Multiplication table:\n");
    for (int i = 1; i <= 10; i++) {
        printf("%d * %d = %d\n", a, i, a * i);
    }
    return 0;
}

🎯 Factorial with a For Loop

Factorial of n (written n!) = n × (n-1) × (n-2) × ... × 1
Example: 5! = 5 × 4 × 3 × 2 × 1 = 120

#include <stdio.h>
int main() {
    int num;
    long int fact = 1;
    printf("Enter a number: ");
    scanf("%d", &num);

    for (int i = 1; i <= num; i++) {
        fact = fact * i;   // or: fact *= i;
    }

    printf("Factorial of %d is %ld\n", num, fact);
    return 0;
}

    scanf("%d", &num_rounds);

    for (int round = 1; round <= num_rounds; round++) {
        earned = base_xp * round;
        total += earned;
        printf("Round %d: You earned %d XP\n", round, earned);
    }

    printf("\nTotal XP earned: %d\n", total);
    return 0;
}

⏳ The While Loop

Use a while loop when you DON'T know exactly how many iterations you need — the loop runs as long as a condition remains true.

Syntax — Simple but Powerful

// Initialise counter BEFORE the loop
int i = 0;

while (condition) {
    // loop body
    i++;   // increment counter INSIDE loop (or you'll loop forever!)
}

🔁 For Loop

All 3 parts in one line:
for(init; cond; incr)

Counter declared and managed IN the loop header.

⏳ While Loop

Only condition in header:
while(cond)

You manage init and increment manually OUTSIDE/INSIDE loop.

🎮 When to use which?

  • for loop → You KNOW the count: "print 10 times", "loop through 5 items"
  • while loop → You DON'T know the count: "keep asking until valid input", "keep running until player dies"

Do...While Loop

A special variant — the body executes at least ONCE before checking the condition. Perfect for menus!

do {
    // body always runs at least once
} while (condition);

Textbook Shoe Shop — Do...While Example

#include <stdio.h>
int main() {
    int meal;
    char ch;
    do {
        printf("Welcome to the shoe shop. Please select your brand:\n");
        printf("1. Liberty\n2. Nike\n3. Reebok\n4. Adidas\n");
        printf("Please enter your selection: ");
        scanf("%d", &meal);
        switch(meal) {
            case 1: printf("You have ordered Liberty shoes\n"); break;
            case 2: printf("You have ordered Nike shoes\n"); break;
            case 3: printf("You have ordered Reebok shoes\n"); break;
            case 4: printf("You have ordered Adidas shoes\n"); break;
            default: printf("Wrong entry\n");
        }
        printf("Enter choice(Y/N): ");
        scanf("%c", &ch);
        ch = getchar();
    } while (ch == 'Y' || ch == 'y');
    return 0;
}
🧪 LAB 7

Sum Until Zero — While Loop

Write a program that keeps accepting numbers from the user and adds them together. It stops when the user enters 0, then prints the total. You don't know how many numbers they'll enter — perfect for while!

  • Declare: int num, total = 0;
  • Get the first number BEFORE the loop
  • Loop while num != 0
  • Inside loop: add to total, get next number
  • After loop: print total
The pattern for while with user input is: get input → check → process. Read the first number BEFORE the while: scanf("%d", &num); then while (num != 0) { total += num; scanf("%d", &num); }
Why read the number before the loop? Because the while condition needs to see it first! If you read INSIDE the loop, you can't check it in the while() condition on the first pass. 
#include <stdio.h>
int main() {
    int num, total = 0;
    printf("Enter numbers (0 to stop):\n");
    scanf("%d", &num);     // Read FIRST number before loop

    while (num != 0) {
        total += num;       // Add to running total
        scanf("%d", &num); // Read NEXT number (loop continues if != 0)
    }

    printf("Total sum: %d\n", total);
    return 0;
}

🛠 Refactor: For vs While — The Factorial Challenge

🎯 The Big Idea

A for loop and a while loop can do EXACTLY the same thing — they're just different syntax for the same idea. The key insight: any for loop can be rewritten as a while loop and vice versa!

Version 1 — Factorial with For Loop (You already saw this!)

#include <stdio.h>
int main() {
    int num;
    long int fact = 1;
    printf("Enter a number: ");
    scanf("%d", &num);

    for (int i = 1; i <= num; i++) {
        fact *= i;
    }

    printf("Factorial of %d is %ld\n", num, fact);
    return 0;
}

🤔 Now think about this...

In the for loop version, can you identify the 3 parts?

  • Initialisation: int i = 1
  • Condition: i <= num
  • Increment: i++

To convert to while, you simply move these 3 parts to different places! The initialisation goes BEFORE the while. The condition goes IN the while(). The increment goes at the END of the loop body.

🧪 LAB 8 — The Main Challenge!

Convert the Factorial to a While Loop!

Using what you know, rewrite the factorial program using a while loop instead of for. The output should be IDENTICAL.

  • You need ALL the same variables: num, fact, and a counter
  • Initialise the counter BEFORE the while
  • The while condition takes the place of the for condition
  • The increment must go INSIDE the while body
Start with: int i = 1; declared right after your other variables. This is your counter — it's the same i from the for loop, just declared separately.
Your while condition is: while (i <= num) — this is EXACTLY the same as the middle part of the for loop! The body does the same multiplication: fact *= i;
Don't forget to put i++ at the END inside the while body! If you forget it, i never changes, the condition is always true, and you get an infinite loop — just like accidentally leaving the increment out of a for loop! 
#include <stdio.h>
int main() {
    int num;
    long int fact = 1;
    int i = 1;   // ← init moved OUT of loop header

    printf("Enter a number: ");
    scanf("%d", &num);

    while (i <= num) {  // ← condition same as for
        fact *= i;       // ← body same as for
        i++;             // ← increment moved INTO body
    }

    printf("Factorial of %d is %ld\n", num, fact);
    return 0;
}

FOR Version

int i; // inside header
for(i=1; i<=n; i++) {
    fact *= i;
}

WHILE Version

int i = 1; // BEFORE loop
while(i <= n) {
    fact *= i;
    i++; // INSIDE loop
}

🎯 Both produce IDENTICAL output! The structure is the same — the syntax is just arranged differently. In professional code, for is preferred when you know the count; while is preferred for open-ended loops.

✅ One More: Bonus For vs While Side by Side

Times Table (For)

for (i=1; i<=12; i++) {
    printf("%d x %d = %d\n",
        n, i, n*i);
}

Times Table (While)

i = 1;
while (i <= 12) {
    printf("%d x %d = %d\n",
        n, i, n*i);
    i++;
}
